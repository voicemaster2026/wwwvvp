# DataVision offline reference archive

This folder contains a local copy of [datavision.software](https://www.datavision.software/) captured on 2026-10-26 for offline design reference. It includes 82 HTML pages, 1,289 downloaded CDN assets (including media variants, styles, scripts and fonts), and linked PDF/feed resources. Internal navigation and downloaded asset links point to local files.

The pages, media, text, trademarks and other content belong to DataVision Software and their respective owners. The archive preserves source attribution. Contact forms, streamed media, maps and other server-backed services remain online-only. The manifest records the capture source, file counts and the small number of unavailable Wix service/source-map endpoints.

Open `index.html` directly or serve the repository root over HTTP and visit `/datavision-offline/`.

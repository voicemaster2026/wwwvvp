# VoiceVision Platform website

Responsive Czech-language presentation of VoiceVision Platform (VVP), built with plain HTML and CSS.

## Preview

Open `index.html` in a browser or serve this directory with any static web server.

## Content

The site describes VVP as a machine-vision workspace that brings together Studio, a shared runtime, command interface, and device adapters. Product statements are based on the VoiceVision Platform repository and its project overview.

## Branding

The header and footer use the official VoiceVision wordmark copied from
`voicemaster2026/voicevisionunited` (`assets/branding/voicevision-wordmark.png`,
source revision `47a5817fba6e6a5c5840b687b5a46e296447d598`). The source image is
preserved unchanged; CSS applies a monochrome filter for contrast on the light
site background.

The matching official app mark is included as `assets/voicevision-icon.png` and
used as the website favicon. The Omarchy desktop launcher points to a local copy
of this same icon at `~/.local/share/icons/voicevision-platform.png`.

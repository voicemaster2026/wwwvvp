02 RUNTIME A CLI · PRINCIPY

Čtení, změna a spuštění
nejsou zaměnitelné kroky.

Každý příkaz má deklarovaný vstup, zvolený adaptér a strukturovaný výstup. Runtime vrací výsledek, který může obsahovat potvrzení zařízení, naměřené hodnoty nebo známé omezení operace.

CLI je terminálové rozhraní do stejného katalogu operací. Dostupný příkaz se před použitím řídí konfigurací, allowlistem a podmínkami konkrétního zařízení.
